# BSUIR Hub — MVP

Современное мобильное и веб-приложение для студентов и преподавателей Белорусского государственного университета информатики и радиоэлектроники (БГУИР).

---

## 🌟 Основные возможности

1. **Персонализированный онбординг**:
   - Выбор роли: **Студент** или **Преподаватель**.
   - Поиск реальной студенческой группы с фильтрацией по курсу, факультету и специальности.
   - Выбор подгруппы (Вся группа / 1-я подгруппа / 2-я подгруппа).
   - Поиск преподавателя по ФИО и кафедре из актуального справочника.
   - Сохранение настроек в локальном хранилище без необходимости ввода паролей.

2. **Главный экран студента**:
   - Персональное приветствие, текущая дата, номер группы и текущая учебная неделя (1–4 цикл БГУИР).
   - **Карточка ближайшей пары** — главный визуальный якорь:
     - Название дисциплины, тип занятия (Лекция, Практика, Лабораторная), время, аудитория и корпус, подгруппа.
     - Интеллектуальный таймер статуса («Сейчас идёт · ещё X мин», «Начнётся через X мин», «Следующая пара завтра»).
   - **Блок «Расписание на сегодня»** в хронологическом порядке с подсветкой текущей пары и приглушением прошедших.
   - Блок экзаменов и быстрых действий.

3. **Главный экран преподавателя**:
   - Приветствие с ФИО преподавателя, кафедра.
   - Ближайшая пара с указанием студенческих групп и аудитории.
   - Список занятий преподавателя на текущий день.

4. **Экран расписания**:
   - Режимы отображения: **«День»**, **«Неделя»** и **«Экзамены»**.
   - Горизонтальный календарь с днями недели (Пн–Сб).
   - Переключение между 1-й, 2-й, 3-й и 4-й учебными неделями с индикатором текущей академической недели.
   - Фильтрация по подгруппам (Все / 1 / 2) и типам занятий (Лекции / Практики / Лабы).
   - Цветовая дифференциация:
     - Лекция (Индиго)
     - Практика (Изумруд)
     - Лабораторная (Янтарь)
     - Консультация (Фиолетовый)
     - Экзамен (Красный)
   - Аккуратное состояние «Занятий нет» для свободных дней.

5. **Глобальный поиск**:
   - «Живой» поиск по номеру группы и ФИО преподавателя.
   - Обработка неполного ввода, игнорирование регистра и нормализация букв «е» и «ё».
   - Переключатели категорий: «Все», «Преподаватели», «Группы», «Избранное».
   - Просмотр расписания любой группы прямо из поиска.

6. **Профиль преподавателя**:
   - Аватар с инициалами / фотографией из ИИС.
   - Кафедра, учёная степень и звание.
   - Расписание на сегодня и всю неделю.
   - Список преподаваемых дисциплин и групп.
   - Кнопка добавления в избранное.
   - Кнопка **«Когда можно встретиться?»**.

7. **Поиск общего свободного времени («Когда можно встретиться?»)**:
   - Анализ расписания группы студента и преподавателя на выбранный день и учебную неделю.
   - Расчёт окон без занятий у обеих сторон в интервале 08:00 — 19:30 (длительностью от 30 минут).
   - Чёткая маркировка: «Потенциальное свободное время по расписанию» с академическим дисклеймером.

8. **Избранное**:
   - Быстрое добавление преподавателей и групп в избранное одним касанием.
   - Отдельная вкладка в поиске для быстрого переключения.

9. **Обнаружение изменений расписания (Diff Engine)**:
   - Сохранение снимков расписания при загрузке.
   - Сравнение с предыдущей версией при обновлении.
   - Детекция добавленных, отменённых и изменённых пар (аудитории, времени).
   - Счётчик на колокольчике уведомлений и шторка со списком недавних изменений.

10. **PWA и Офлайн-режим**:
    - Web App Manifest и Service Worker (`vite-plugin-pwa`).
    - Кеширование расписания в LocalStorage.
    - Индикатор «Офлайн-режим» при отсутствии сети.
    - Встроенная кнопка установки PWA и инструкция для iOS Safari.

11. **Профиль и Настройки**:
    - Переключение темы: Светлая / Тёмная / Системная.
    - Быстрая смена подгруппы и роли.
    - Управление системными уведомлениями.
    - Сброс локальных данных.
    - Информация о приложении и источнике данных.

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React, date-fns.
- **PWA**: `vite-plugin-pwa`, Web App Manifest, Service Worker.
- **Backend**: Node.js 22, Express, `bsuir-iis-api` (официальный клиент ИИС БГУИР).
- **Кеширование**:
  - Серверный in-memory LRU-кэш со сроком жизни (TTL) для снижения нагрузки на серверы университета.
  - Клиентский офлайн-кэш расписаний и справочников.

## 🚀 Инструкция по запуску

### Запуск в режиме разработки:
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000` (Express монтирует Vite middleware).

### Запуск тестов:
```bash
npm test
```
Запускает 10 автоматических тестов для всех ключевых сценариев:
- Выбор студента и группы
- Выбор преподавателя
- Получение расписания и сортировка
- Фильтрация по подгруппам
- Определение текущей учебной недели
- Определение ближайшей пары
- Поиск преподавателей с нормализацией «е»/«ё»
- Сопоставление свободных временных окон
- Обнаружение изменений расписания
- Офлайн-кеширование и сериализация

### Сборка:
```bash
npm run build
```

## ⚠️ Текущие ограничения MVP

1. **Запись на консультацию**: Функция «Когда можно встретиться?» рассчитывает потенциальные свободные окна на основе расписания пар, но не является системой записи на приём, так как открытый API ИИС БГУИР не предоставляет подтверждённых слотов консультаций преподавателей.
2. **Личные сообщения и оценки**: Не входят в рамки публичного API ИИС БГУИР без OAuth-авторизации личного кабинета студента.
3. **Фоновые push-уведомления при закрытом браузере**: Для автономной доставки push-уведомлений в закрытом приложении требуется настройка внешнего VAPID/WebPush сервера и регистрация подписок (в MVP изменения расписания автоматически отслеживаются и отображаются при каждом открытии и обновлении приложения).
